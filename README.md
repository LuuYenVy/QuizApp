# Quiz App

This is a simple quiz application built using the **Flutter framework**. The app allows users to answer a series of questions and then provides feedback on their performance.

## Features:
- **Question Display:**  
  The app presents multiple-choice questions to the user.
- **Answer Selection:**  
  Users can select their answers and proceed through the quiz.
- **Result Review:**  
  After completing the quiz, the app shows a summary of correct and incorrect answers for comparison.
- **Score Calculation:**  
  The app calculates the total score based on the user's responses and displays the final result.

## Key Technologies:
- Built using the **Flutter framework** for a smooth and responsive user interface.
- User-friendly design for seamless interaction and easy navigation through the quiz.

This project demonstrates my skills in **Flutter development**, UI design, and creating interactive mobile applications. It offers a simple yet effective way to engage users and test their knowledge on various topics.
